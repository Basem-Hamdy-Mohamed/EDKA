# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:
- Be respectful and constructive. Critique ideas and code, not people.
- No harassment, insults or personal attacks, in any language.
- Do not post copyrighted standards, confidential project documents or anyone's personal data in
  issues, pull requests or examples.

To report a problem, open a private security advisory on the repository or contact the maintainer
through their GitHub profile. Reports are handled confidentially. The maintainer may remove content
and block participants who break these rules.
